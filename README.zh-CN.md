![工程蓝图图版 I：15 节点证据图谱控制平面与三大旗舰游戏垂直切片实例化拓扑](assets/svg/architecture-pipeline-zh-CN.svg)

第一卷确立了三大游戏共享的四项核心工程铁律：

1. **15 节点有向带环控制平面（`N00_BRIEF` .. `N14_RELEASE_CANDIDATE`）**：由 [`schemas/graph-state.d.ts`](schemas/graph-state.d.ts) 严格定义。任何节点若未能提供通过 JSON Schema 校验的 [`TaskPacket`](schemas/task-packet.schema.json) 与终端验收命令输出，编排器绝不允许推进状态；验收失败将触发有界回滚环路（`N13_REPAIR_ROUTER -> N05..N08`，单节点最多 `3` 次修复，全局最多 `8` 次回滚）。
2. **7 个文件所有权物理隔离的专职子智能体角色**：每款游戏均由 7 张职责正交的专职角色卡（`combat_gameplay`、`world_quest`、`procedural_art_vfx`、`procedural_audio`、`ui_hud_accessibility`、`qa_perf_playwright` 及只读评审 `independent_critic`）协同构建，严禁越权修改 `allowed_paths` 之外的代码或篡改验收标准。
3. **双轨确定性体制（`A-PinnedBrowser` 与 `B-CrossPlatform`）**：
   - **体制 A（`A-PinnedBrowser`）**：在固定版本 Chromium + GPU/SwiftShader 容器内执行比特级 SHA-256 校验，涵盖 60 Hz 整数模拟帧（`state_hash`）、16-bit PCM 量化离线音频渲染（`audio_hash`）与 `1e-5` 量化顶点缓冲区（`geometry_hash`）。
   - **体制 B（`B-CrossPlatform`）**：在跨平台 `THREE.WebGPURenderer` 与 `{ forceWebGL: true }` 回退路径上执行有界不变量与感知容差门禁（`P50 <= 8.3 ms`、`P95 <= 16.6 ms`、`P99 <= 22.0 ms`、响度 `-16 LUFS +- 1.0 LU`、真峰值 `<= -1.0 dBTP`）。
4. **反 AI 劣质审美（Anti-Slop）与零外部资产溯源门禁（`provenance_critic`）**：严禁运行时请求任何外部 `.glb/.gltf/.fbx/.obj/.png/.jpg/.wav/.mp3/.ogg` 资源，并在所有着色器与 UI 层中明令封杀通用 AI 霓虹紫（`#7567F5`）。
